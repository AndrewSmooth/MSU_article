# Экспериментальный прототип

Минимальный стенд для сравнения случайной и основанной на трассировке стратегий выбора точек отказа. Текущая версия реализует контрольный сценарий и управляемое воспроизведение дефекта `B1`.

## Что уже работает

- `order-service` создаёт заказ, вызывает платёж и публикует событие;
- `payment-service` регистрирует платёж;
- `notification-service` получает событие `order.paid` из Kafka;
- PostgreSQL хранит заказы, платежи, попытки, события и уведомления;
- OpenTelemetry Collector передаёт единую трассу в Jaeger;
- контрольный скрипт автоматически проверяет пять инвариантов из [EXPERIMENT_SPEC.md](EXPERIMENT_SPEC.md);
- `payment-service` принимает конфигурацию отказа через служебный API;
- эксперимент `B1` воспроизводит повторный платёж после потери ответа и записывает результат в JSONL.

## Запуск

Из PowerShell в этом каталоге:

```powershell
.\start.ps1
```

Первый запуск скачивает Docker-образы и собирает три Python-сервиса. После запуска доступны:

- документация API: <http://localhost:8000/docs>;
- Jaeger: <http://localhost:16686>;
- PostgreSQL: `localhost:5432`;
- Kafka: `localhost:9092`.

## Контрольный эксперимент

```powershell
.\control.ps1
```

Команда создаёт заказ, ждёт обработки события и завершается ошибкой, если нарушен хотя бы один инвариант. Успешный результат содержит:

- один платёж;
- одну попытку оплаты;
- одно опубликованное событие;
- одно уведомление;
- `all_passed: true`.

После запуска в Jaeger нужно выбрать сервис `order-service`. Трасса операции `POST /orders` должна включать также `payment-service` и `notification-service`.

## Эксперимент B1

```powershell
.\experiment-b1.ps1
```

Скрипт включает отказ `lost_response` в точке `payment.http.response.after_commit`. Первый платёж сохраняется, но `order-service` не получает ответ до истечения тайм-аута и повторяет запрос. Ожидаемый результат:

- созданы два платежа;
- выполнены две попытки;
- нарушен инвариант `I1_single_payment`;
- обнаружен дефект `B1`;
- запись добавлена в `results/experiments.jsonl`.

## Полный сброс

```powershell
.\reset.ps1
```

Команда останавливает стенд и удаляет тома PostgreSQL и Kafka. Следующий вызов `start.ps1` создаёт стенд с чистым состоянием.
